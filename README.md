# Heart_Disease_Prediction
Machine learning project to predict heart disease using Python and scikit-learn. Includes data preprocessing, model training, and evaluation. Built in Google Colab.

# Run The Notebook
You can open and run this project directly in Google Colab using the link below:
[Open in Colab] (https://colab.research.google.com/drive/1rj28q9XnMd18yTeKhevqM7JOT6uybguI?usp=sharing)

# Dataset
The dataset was obtained from [Kaggle - Heart Disease Dataset](https://www.kaggle.com/datasets/johnsmith/heart-disease-dataset). 
It includes patient health attributes and a target variable indicating heart disease diagnosis.
